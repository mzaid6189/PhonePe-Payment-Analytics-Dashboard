
# 📊 PhonePe Payment Analytics Dashboard

An interactive **PhonePe Payment Analytics Dashboard** developed using **Microsoft Power BI** to analyze payment transactions, transaction value, users, service categories, customer demographics, payment status, and transaction trends.

The dashboard combines **data cleaning, DAX measures, KPI development, MoM & YoY analysis, interactive visuals, slicers, and custom tooltips** to transform raw transaction data into meaningful business insights.

---

## 📌 Project Overview

The objective of this project is to develop an interactive payment analytics dashboard that provides a clear overview of transaction performance and customer behavior.

### Key Areas of Analysis

- 💳 Total Transactions
- 💰 Total Transaction Value
- 👥 Unique Users
- ✅ Payment Success Rate
- 📈 Monthly Transaction Trends
- 👤 Age Segment Contribution
- 🏦 Service-wise Transaction Value
- 🏆 Top 5 Users by Transaction Value
- 📅 Weekday vs. Weekend Usage
- 🔄 Payment Status
- 📊 Month-over-Month (MoM) Performance
- 📆 Year-over-Year (YoY) Performance

## 📈 Dashboard Visualizations

### 1. Transactions Over Time

A time-series visualization showing transaction trends across different months.

**Key Analysis:**

- Monthly transaction patterns
- Growth trends
- High and low transaction periods
- Changes in transaction activity

---

### 2. Age Segment Contribution

A donut chart showing the contribution of different customer age segments.

**Age Segments:**

- Gen X
- Millennials
- Gen Z
- Boomers

---

### 3. Service Transaction Value Analysis

A bar chart comparing transaction value across different services.

**Services:**

- Loans
- Insurance
- Money Transfer
- Recharge Bills

This visualization helps identify the services contributing the highest transaction value.

---

### 4. Top 5 Users

Displays the **Top 5 users based on transaction value**.

This analysis helps identify high-value customers and their contribution to overall transaction activity.

### 5. Weekday vs. Weekend Usage

Analyzes transaction usage between weekdays and weekends to identify customer activity patterns.

---

### 6. Payment Status Analysis

The dashboard allows analysis based on payment status:

- 🟢 Successful
- 🟡 Pending
- 🔴 Failed

---

### 7. Transaction Trend Analysis

## 📅 Month-over-Month (MoM) Analysis

**Month-over-Month (MoM)** analysis compares the current month's performance with the previous month.

### Analysis Includes

- Transaction volume
- Transaction value
- User activity
- Overall payment performance

MoM analysis helps identify short-term changes and monthly growth patterns.

---

## 📆 Year-over-Year (YoY) Analysis

**Year-over-Year (YoY)** analysis compares performance with the corresponding period of the previous year.

### Analysis Includes

- Long-term growth
- Annual performance changes
- Overall business trends
